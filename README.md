# ScaleForge – Autonomous Growth Engines

> Engineering-grade B2B revenue infrastructure & automated client acquisition pipelines for high-growth enterprise operators.

## 🚀 Overview

ScaleForge is a modern, modular revenue engineering platform that converts cold B2B prospects into pre-qualified, sales-ready calendar appointments. Built with high-performance React 19, TypeScript, Tailwind CSS, and modular component architecture.

---

## ⚡ Core Features

- **Autonomous 4-Stage Architecture**: Intent discovery, high-conversion landers, automated SDR pre-qualification bots, and direct CRM calendar bookings.
- **Interactive Lead-to-Meeting Pipeline Simulator**: Live sandbox letting operators customize ICP targets, adjust deal size (ACV) and discovery volume, and simulate outbound velocity in real time.
- **14-Day Deployment Roadmap**: Clear, milestone-driven execution highway with deliverability warming and verification safeguards.
- **Contractual SLA Risk Reversal**: Written 30-day performance benchmarks with legally counter-signed guarantees.
- **Diagnostic Strategy Session Intake**: Integrated consultation booking engine with automated qualification filtering.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Plus Jakarta Sans typography
- **Routing**: React Router DOM (with sub-millisecond route prefetching)
- **Icons & Animation**: Lucide React + Motion

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The application will start on `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```

### 4. Type & Lint Check
```bash
npm run lint
```
